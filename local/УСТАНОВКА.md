# Директор на вашем компьютере

Без сервера и без домена. Директор работает, пока включён компьютер; когда
выключаете — не работает, и это нормально.

## Что понадобится

**Docker Desktop** — бесплатная программа, внутри которой всё и крутится.
Скачать: https://www.docker.com/products/docker-desktop/

Больше ничего ставить не нужно: ни Python, ни базу данных.

## Установка

**1. Установите Docker Desktop и запустите его.** В первый раз он попросит
перезагрузку. Дождитесь, пока значок кита перестанет мигать.

**2. Распакуйте папку с Директором** куда удобно — например, в «Документы».

**3. Запустите:**

- **Windows** — двойной щелчок по `local\Запустить.bat`
- **Mac** — двойной щелчок по `local/Запустить.command`

Первый запуск скажет, что нужно заполнить настройки, и создаст файл `.env`
в корне папки.

**4. Откройте `.env` любым текстовым редактором** и заполните всё, что стоит
в угловых скобках. Что это за значения — написано в самом файле рядом с
каждой строкой.

Отдельно про пароли: они должны быть не короче двенадцати символов. Программа
не запустится с коротким — это сделано нарочно, за паролями лежат телефоны
клиентов.

**5. Запустите ещё раз.** Первая сборка занимает несколько минут: Docker
скачивает и собирает всё нужное. Дальше запуск — секунды.

Когда увидите `Директор запущен: http://localhost:8000` — откройте этот адрес
в браузере. Браузер спросит логин и пароль, введите те, что записали в `.env`.

## Каждый день

**Включить:** `Запустить.bat` или `Запустить.command`
**Выключить:** `local/stop.sh`, либо просто выключите компьютер

Данные остаются на месте между запусками. При включении Директор сразу
подтягивает из YCLIENTS всё, что произошло, пока его не было.

## Чтобы видели и остальные

По умолчанию Директор открывается только на том компьютере, где стоит.
Чтобы его видели администратор со стойки и мастера со своих телефонов,
добавьте в `.env` строку:

```
BIND_HOST=0.0.0.0
```

После перезапуска скрипт покажет второй адрес — вида `http://192.168.1.50:8000`.
Его и давайте остальным. Работает только внутри салонной сети.

**Подумайте, прежде чем включать.** На страницах — имена и телефоны клиентов.
Если салонный вайфай общий с гостевым, ваши клиенты окажутся видны чужим
людям. Тогда лучше завести отдельную сеть для своих.

## Если что-то пошло не так

**«Docker не установлен»** — поставьте Docker Desktop по ссылке выше.

**«Docker установлен, но не запущен»** — откройте Docker Desktop и подождите,
пока он загрузится. Он должен быть запущен всё время, пока работает Директор.

**«В .env остались незаполненные значения»** — скрипт покажет строки с
номерами. Заполните их.

**«Приложение не запустилось»** — скрипт напечатает последние строки журнала.
Пришлите их мне, по ним видно причину.

**Порт 8000 занят другой программой** — добавьте в `.env` строку
`APP_PORT=8080` и запустите заново. Адрес станет `http://localhost:8080`.

## Что дальше

Когда понадобится доступ из дома или от мастеров вне салона — Директор
переезжает на российский VPS. Переезд это копирование папки и запуск той же
команды: переписывать ничего не придётся.
