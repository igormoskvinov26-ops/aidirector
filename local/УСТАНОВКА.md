# Директор на вашем компьютере

Инструмент работает на самом компьютере, без сервера и без ежемесячной
платы. Данные берутся из YCLIENTS напрямую.

Docker Desktop ставится руками в обоих случаях. Дальше на **Windows** —
установщик: один файл, ни вопросов, ни прав администратора. На **macOS**
установщика нет: заполняются настройки и запускается один файл.

## Что понадобится

**Docker Desktop** — бесплатная программа, в которой Директор работает.
Скачать: https://www.docker.com/products/docker-desktop/

Важно: Docker Desktop должен быть запущен, пока вы пользуетесь Директором.

Требования к системе, объём установки и расход памяти указаны на странице
загрузки и в самой программе: раздел Settings → Resources. Там же они
настраиваются. Здесь эти числа не приводятся: они зависят от версии
программы и от компьютера, а неточность в документации хуже её отсутствия.

Важно другое: Docker Desktop должен быть запущен, пока вы пользуетесь
Директором. Закрыли программу — Директор перестал отвечать. Данные при этом
сохраняются.

**Ключи YCLIENTS** — три значения. Где взять, написано ниже.

## Установка, Windows

Два шага: Docker Desktop, потом установщик Директора.

### 1. Docker Desktop

Ставится один раз, отдельно — в нём проходят регистрацию, а её всё равно
делают руками.

* страница загрузки: https://www.docker.com/products/docker-desktop/
* прямая ссылка на файл (64-бит, Intel/AMD):
  https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe

Установить, зарегистрироваться, открыть и дождаться, пока запустится.
Попросит перезагрузку — перезагрузите.

Требования Docker к системе: Windows 10 версии 22H2 (сборка 19045) или
Windows 11 версии 23H2 (сборка 22631) и новее.

### 2. Установщик Директора

Один файл — **`РублЪ-Директор-Установка.exe`**.

1. Положите рядом с ним файл настроек под именем **`настройки.env`**

   Это обычный `.env` с рабочего компьютера — тот, что уже заполнен ключами
   YCLIENTS и паролями. Скопируйте его и переименуйте.

   Зачем: придумать ваши ключи установщик не может. Один раз подготовили
   файл — и дальше установка на любое число компьютеров идёт вообще без
   участия человека.

2. Двойной щелчок

Всё. Прав администратора установщик не просит, вопросов не задаёт. В окне
видно, что происходит: запускается Docker, собирается Директор, готовится
база. Первый раз это несколько минут — сборка идёт из интернета. Когда всё
готово, браузер открывается сам.

**Каждый день ничего запускать не нужно.** Директор поднимается сам при
входе в систему. Значок «Директор» на рабочем столе просто открывает его в
браузере.

Удалить — обычным способом: Параметры → Приложения → РублЪ Директор. База
данных при этом остаётся: при повторной установке всё будет на месте.

### Если файла настроек нет

Директор всё равно поставится, но не запустится — установщик так и скажет.
Тогда: Пуск → РублЪ Директор → **Настройки**, заполнить значения в угловых
скобках (**скобки убрать вместе с текстом внутри**: было
`YCLIENTS_COMPANY_ID=<id филиала>`, стало `YCLIENTS_COMPANY_ID=2036703`),
сохранить и открыть ярлык **«Директор»** на рабочем столе.

### Без установщика

Прежний способ никуда не делся: распаковать архив и запускать
**`local\Запустить.bat`**, останавливать — **`local\Остановить.bat`**.
Настройки заполняются так же.

## Установка, macOS

1. Поставьте Docker Desktop, откройте и дождитесь его запуска
2. Распакуйте архив. Надёжнее — из Терминала, одной строкой:

```
ditto -x -k ~/Downloads/rubl-director.zip ~/
```

   Появится папка `~/rubl-director`. Распаковка через двойной щелчок тоже
   работает, но macOS помечает файлы из интернета и потом не даёт их
   запускать; `ditto` из Терминала такой пометки не оставляет.

   Именно `ditto`, а не `unzip`. Встроенный в macOS `unzip` не понимает
   русские имена файлов: `получить-токен.py` превращается в строку из
   знаков вопроса, система отказывается создавать такой файл, и программа
   сообщает об этом как о переполненном диске. Проверено 17.09.2026.

3. Двойной щелчок по **`local/Запустить.command`** внутри папки

Если macOS всё же отказалась запускать файл — щелчок правой кнопкой по
нему → **Открыть** → в окне подтвердить. Один раз.

Дальше как в Windows: первый запуск создаст `.env`, заполняете, запускаете
снова. Открыть файл настроек: в Терминале `open -e ~/rubl-director/.env`

Остановить — **`local/Остановить.command`**

## Что писать в настройках

| Строка | Где взять |
|---|---|
| `YCLIENTS_PARTNER_TOKEN` | настройки YCLIENTS, раздел для партнёров |
| `YCLIENTS_COMPANY_ID` | `2036703` — это ваш филиал |
| `YCLIENTS_USER_TOKEN` | выдаётся по логину и паролю, см. ниже |
| `POSTGRES_PASSWORD` | любой длинный набор символов, вводить его не придётся |
| `OWNER_LOGIN` / `OWNER_PASSWORD` | придумайте — это вход для владельца |
| `OPERATOR_LOGIN` / `OPERATOR_PASSWORD` | вход для администратора салона |
| `MASTER_ACCOUNTS` | по одной записи на мастера, пароли придумайте |

Пароли входа — минимум 12 символов, иначе приложение не запустится.
Ограничение установлено намеренно: при доступе из локальной сети короткий
пароль подбирается перебором за считанные минуты.

Пароли можно придумывать свои, генератор из терминала — только удобство.
Что нужно знать про сам файл настроек (проверено на его разборщике):

* пробелы внутри значения работают: `ножницы расческа фен` читается целиком;
* кавычки по краям снимаются, лишние пробелы по краям обрезаются;
* **решётка после пробела обрезает всё, что правее**, молча: из
  `parol #хвост` останется `parol`. Решётка без пробела перед ней —
  безопасна;
* `${` считается подстановкой, и содержимое фигурных скобок исчезает;
* для пароля входа берите латиницу. В файле русские буквы читаются верно,
  но вводится пароль в окне браузера, а стандарт этого окна кодировку не
  закрепляет — вход может не пройти. Русские слова латиницей подходят.

`POSTGRES_PASSWORD` своим делать не нужно: он подставляется в адрес
подключения к базе, и знаки `/ @ :` этот адрес разорвут. Только
`openssl rand -hex 24` — вводить его руками не придётся никогда.

**Пользовательский токен YCLIENTS** в настройках не показывают — его выдают
в обмен на логин и пароль сотрудника. Получить:

```
cd backend && uv run python "../scripts/получить-токен.py"
```

Если `uv` не установлен: `curl -LsSf https://astral.sh/uv/install.sh | sh`

Не уверены, что за филиал — спросите у YCLIENTS:

```
cd backend && uv run python "../scripts/показать-филиалы.py"
```

## Каждый день

**Включить:** `Запустить.bat` или `Запустить.command`
**Выключить:** `Остановить.bat` / `Остановить.command`, либо просто выключите
компьютер

На Windows, если ставили установщиком, включать не нужно вовсе: Директор
поднимается сам при входе в систему, а значок на рабочем столе открывает его
в браузере.

Это файлы для двойного щелчка: в конце они ждут Enter, иначе Finder закроет
окно прежде, чем вы успеете прочитать адрес или ошибку.

**Из Терминала запускайте `./start.sh` и `./stop.sh`** — то же самое, но без
ожидания в конце. Если запустить оттуда `.command`, это ожидание съест
следующую вставленную строку вместо Enter, и команда молча не выполнится.

**Обновить до последней версии:** `./local/update.sh` из Терминала. Тянет
изменения из той же ветки, что уже стоит на компьютере, и перезапускает.
Если в рабочей копии есть свои несохранённые правки — остановится и ничего
не тронет, чтобы их не затереть.

Данные сохраняются между запусками. При включении Директор сразу подтягивает из
YCLIENTS всё, что произошло, пока его не было.

## Журнал обзвона

Каждый отмеченный звонок попадает в `output/обзвон.xlsx` — обычная таблица
Excel рядом с проектом. Открывается без Директора, пригоден для любых расчётов.

Файл только пополняется. При переносе на другой компьютер скопируйте его с
собой: на вкладке **Клиенты → Администратор** есть кнопка «Загрузить журнал»
(видна только владельцу). Прежние записи добавятся к новым, повторы будут отброшены.

## Чтобы видели и остальные

По умолчанию Директор открывается только на том компьютере, где стоит.

Чтобы заходили из салона — администратор со стойки, мастера с телефонов —
в `.env` поменяйте:

```
BIND_HOST=0.0.0.0
```

После перезапуска скрипт напечатает адрес для локальной сети.

Что это означает по существу: Директор станет доступен любому устройству в
той же сети, без пароля на уровне сети — только логин и пароль самого
Директора. На страницах обзвона выводятся имена и телефоны клиентов.

Решение принимайте исходя из того, кто имеет доступ к вашей сети. Если сеть
только для сотрудников — открывать безопасно. Если к ней подключается
кто-то ещё, разумнее оставить доступ с одного компьютера.

## Две установки, салон и дом

Ставится одинаково в оба места. Каждая работает со своей базой и своими
данными — общего между ними только YCLIENTS.

Значит расходятся: план на месяц, сумма расходов, и результаты обзвона.
План и расходы впишите одинаково в обеих. Обзвон ведите **только в салоне** —
иначе часть звонков окажется в одном журнале, часть в другом.

## Если что-то пошло не так

**Windows: «Не удаётся запустить сценарий».** Windows не даёт выполнять
скрипты. `Запустить.bat` обходит это сам, поэтому запускайте именно его, а
не `start.ps1` напрямую.

**macOS: «Не удалось открыть, неизвестный разработчик».** Правая кнопка по
файлу → Открыть → подтвердить.

**«Docker установлен, но не запущен».** Откройте Docker Desktop и дождитесь,
пока программа завершит запуск.

**«В .env остались незаполненные значения».** Скрипт перечислит какие.
Угловые скобки убираются вместе с текстом внутри.

**Долго при первом запуске.** Docker собирает образ: несколько минут на
хорошем интернете. Дальше запуск за секунды.

**Занят порт 8000.** В `.env` поменяйте `APP_PORT=8001`.

## Кто что видит

| Вход | Что доступно |
|---|---|
| Владелец | всё: план-факт, будущие записи, расчёт ЗП по всем, обзвон |
| Администратор | обзвон и общий расчёт ЗП |
| Мастер | только свой расчёт ЗП |

Разграничение выполняется на сервере, а не скрытием пунктов меню: мастер
не получит данные других, даже обратившись к странице напрямую.
