# Остановка выгрузки 28.09.2026 — настоящая причина (исправлено в 9.8)

## Коротко

Выгрузка из YCLIENTS встала 28.09 в 16:41 на шаге «визиты» и двое суток не
обновлялась. Причина — одна запись, в которой YCLIENTS прислал `"client": null`.
Так выглядят перерыв мастера и гость без записи.

Код читал поле как `item.get("client", {}).get("id")`. Значение по умолчанию
`{}` подставляется только тогда, когда поля нет вовсе. Пустое поле `null` даёт
`None`, дальше `None.get(...)` и ошибку
`'NoneType' object has no attribute 'get'`. Падает весь шаг визитов.

Первая версия исправления (9.2) закрыла другую ошибку того же рода — `null` в
поле `data` целого ответа. До записи с `client: null` она не доходила. После
установки 9.7 надпись на экране показала точное место: шаг «визиты».

## Как подтверждено

Ровно эти данные прогнаны на настоящем PostgreSQL:

- прежний код падает с той же ошибкой, слово в слово;
- новый код сохраняет всё, что можно, а запись без клиента законно
  пропускает и называет в журнале.

## Что исправлено в 9.8

- Все поля ответа YCLIENTS, которые могут прийти `null`, читаются через
  четыре функции (`_словарь`, `_записи`, `_деньги`, `_целое`): клиент, мастер,
  товар, список услуг, суммы, количество, длительность. Это касается визитов и
  продаж.
- То же исправлено там, где данные YCLIENTS читаются на лету: свободные окна
  для сторис, страницы операций и сводки.
- Если новая таблица настроек ещё не создана, приложение при запуске не
  падает, а работает на значениях из `.env`. Раньше при обновлении оно могло
  уйти в перезапуск по кругу.
- Установка больше не останавливается на коде возврата `docker compose up`.
  Решает реальная проверка, отвечает ли Директор. Ответ Docker теперь целиком
  пишется в `log\bootstrap.log`.
- PowerShell-скрипт проверен настоящим PowerShell 7.4: разбор без ошибок,
  заполненный `.env` остаётся нетронутым байт в байт.

## Проверки

493 автотеста, в том числе отдельный файл `test_null_fields.py` с записью,
на которой всё встало. Путь обновления «старая база → новая версия →
миграция» прогнан на настоящей базе.

## Как поставить

Запустить `РублЪ-Директор-9.8-Windows.exe` на салонном компьютере. Он ставится
в `%LOCALAPPDATA%\RublDirector` поверх рабочей установки, с прежним `.env`,
прежними логинами и прежней базой. Через минуту после запуска внизу слева
должна смениться дата «Обновлено».
