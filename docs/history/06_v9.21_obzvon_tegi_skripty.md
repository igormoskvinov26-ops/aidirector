# Пульт 9.21.0 — планирование контактов, теги, скрипты, вкладка «Обзвоны»

Собрано 16.10.2026, 621 тест проходит. Решения владельца: общий сервер стоит
за рубежом → на него уходят только `yclients_id` и цифры; запланированный
перезвон клиента из очереди не убирает, только помечает датой; «мастер
клиента» = мастер последнего визита; всё шестью пунктами одним релизом.

## Что в релизе

### 1. Дата следующего контакта

- `clients.next_contact_at`, `next_contact_note`, `next_contact_by`
  (миграция 0015). Поле на клиенте: очередь пересобирается каждый день.
- На карточке: «завтра / через 3 дня / через неделю» + выбор даты, рядом
  строка «о чём договорились», кнопка «снять».
- Клиент остаётся в очереди. Порядок (`get_tasks`): перезвон на сегодня или
  просроченный → необзвонённые по важности сегмента → запланированные на
  будущее → обзвонённые сегодня.
- Если звонить по сегментам повода нет, `refresh_tasks` всё равно заводит
  задачу в группе `callback`, приоритет 6 (выше «потерянных»).

### 2. Фильтры по мастеру и услуге

- В строке задачи `last_master` (мастер последнего завершённого визита) и
  `services` (услуги последних трёх визитов).
- Над очередью три выпадающих списка — мастер, услуга, тег, плюс «сбросить».
  Фильтрация на клиенте: задач в день десятки.

### 3. Теги

- `client_tags` (`code`, `name`, `color`, `exclude_from_calls`, `promo`,
  `sort`) и `client_tag_links`. Четыре стартовых заводятся при первом
  открытии: «Переехал» и «Записывает супруга» (исключают из обзвона),
  «Акция» (promo), «Не реагирует» (просто метка).
- `exclude_from_calls` убирает клиента и из пересборки очереди, и из уже
  построенного списка (если тег повесили после пересборки). Снимается одним
  кликом — тем и отличается от «НЕ ЗВОНИТЬ!».
- Теги ставит администратор прямо с карточки; заводит и удаляет —
  управляющий (роль проверяется на эндпойнте).
- Тег «Не реагирует» ставится руками: автоматически после N недозвонов не
  вешается, чтобы база не вычищала себя тихо.

### 4. Скрипты

- Таблица `scripts` (`kind` = group/tag, `key`, `phone_text`,
  `message_text`). Пустое поле хранится как NULL — это «вернуть стандартный
  текст», стереть скрипт в ноль нельзя.
- Приоритет: скрипт тега → скрипт группы → зашитый в коде. В строке задачи
  приходит `script_source` (`tag:<код>` / `group` / `default`).
- Подстановки: `{имя}`, `{мастер}`, `{услуга}`, `{дней_без_визита}`; старое
  `{name}` поддерживается.
- Страница — Настройки → «Скрипты обзвона» (`frontend/src/CallScripts.tsx`),
  правит только управляющий и Владелец.

### 5. Счётчик контактов

Считается из `contact_attempts`, новых полей нет. На карточке: «контактов 7
(за год 4, записей 1)».

### 6. Вкладка «Обзвоны» и выгрузка на сервер

- Четвёртая вкладка в разделе «Клиенты». Период — неделя / месяц / квартал;
  фильтры по админу, мастеру, услуге. Подгруппы плашками: записались · без
  записи · не дозвонились · запланирован перезвон · исключены из обзвона
  (с причиной — тег или «НЕ ЗВОНИТЬ»).
- `hub.py`: документ `calls:<ГГГГ-ММ>` за 180 дней. Состав полей закрытый —
  `ПОЛЯ_ЗВОНКА` = yclients_id, at, outcome, group_code, admin, was_lost,
  verification. Имени, телефона и комментария там нет, и это проверяется
  тестом `test_на_сервер_уходят_только_id_и_цифры`.
- Входящий документ в свои таблицы не пишется (клиентов с такими id на чужой
  машине может не быть) — он ложится в `AppSetting.hub_calls_cache`, и
  вкладка берёт его, если своей истории звонков нет. Имена подставляются
  локально по `yclients_id`; кого не знаем — «Клиент #12345».

Оговорка для протокола: `yclients_id` — псевдоним, и по 152-ФЗ такие данные
считаются персональными, когда их можно сопоставить с человеком, а
сопоставить их может сам салон через YCLIENTS. Имя и телефон за границу не
уезжают — это главное снижение риска; полностью снять вопрос может только
сервер в России.

## Техника

- Миграция `0015_tags_scripts_callback`, идемпотентная, как и прежние.
- Новые эндпойнты: `GET/POST /tags`, `DELETE /tags/{id}`,
  `POST /clients/{id}/tags/{tag_id}`, `POST /clients/{id}/next-contact`,
  `GET/POST /scripts`, `GET /calls?period=`.
- Тесты: `tests/test_tags_scripts.py` — исключение по тегу, приоритет
  скриптов, порядок очереди с перезвоном, счётчик контактов, состав
  hub-документа, подгруппы вкладки.
