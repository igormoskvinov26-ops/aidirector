## 2. Источник каждого показателя

Мастера берутся из существующего списка `barber_payroll_rules` (Ксения, Арташ, Дмитрий; Виктор туда не входит).

- **Выполнено:** записи YCLIENTS месяца, не удалены, есть клиент, `visit_attendance == 1`, визит уже прошёл. Сумма по `cost_to_pay → cost → first_cost`. Товары не входят. Формула общая с `barber_month`.
- **Визиты и средний чек:** одна запись — один визит. Чек = выполнено / визиты, Δ к прошлому месяцу.
- **Доп. услуги:** сумма `amount` по строкам услуг, чей `id` входит в список допуслуг из настроек. Норма 35 в настройках.
- **Стоимость часа:** выручка / часы графика YCLIENTS (`/staff/schedule`, интервалы `from`–`to`) за дни до текущего момента.
- **Продажи:** `barber_month.load_products`. Доля к услугам, норма ≥10%, недостающая сумма `max(0, услуги×10% − продажи)`.
- **Возвратность:** `finance.get_return_rate` на конец месяца.
- **Сделано записей (админ):** запись создана в месяце. Нужны подтверждённые поля даты создания и автора.
- **Закрыто записей (админ):** выполненная запись месяца, автор которой этот администратор.
- **Обзвон:** таблица `contact_attempts`, месяц по времени нажатия (Москва).

## 4. Связь звонка с YCLIENTS

Прямой связи «звонок → запись» в YCLIENTS нет, поэтому работает окно атрибуции (настройка, по умолчанию 3 дня). Проверка ищет запись того же `client_id`, созданную после нажатия и в пределах окна. Одна запись подтверждает один звонок (ближайший по времени). Пока окно открыто, статус `pending`. Если YCLIENTS недоступен, статус `error`. `not_confirmed` ставится только после закрытия окна и удачной загрузки. Другая кнопка при появившейся записи даёт расхождение, результат не правится. Позже отменённая запись остаётся подтверждённой, но «закрытой» не считается.

## 5. Возвратность

Решение владельца 18.09: возврат — второй и любой следующий завершённый визит к тому же мастеру, без срока. В месячном отчёте та же формула на конец выбранного месяца (выбрано владельцем 30.09).

## 6. Источник часов

График YCLIENTS (выбрано владельцем 30.09). Разбор рассчитан на интервалы вида `{"from": "10:00", "to": "22:00"}`. Если формат другой, стоимость часа не считается и показывает «нет данных» с причиной.

## 9. Ограничения

- Поля даты создания и автора записи в YCLIENTS не подтверждены в проекте. Они задаются в настройках после «Проверить поля». Пока не заданы, «Сделано/Закрыто» по администраторам показывают «нет данных», а проверка звонков остаётся в `pending`.
- «Закрыто записей» считается по автору записи: другой связи закрытия с администратором в проекте нет. Определение требует подтверждения владельца.
- Записи берутся по дате визита до горизонта (по умолчанию 60 дней вперёд). Запись, созданная на визит дальше горизонта, не будет найдена при проверке звонка.
- Старые нажатия с именем `admin` идут отдельной строкой «Администратор не указан».
- Возвратность ограничена глубиной базы (окно синхронизации 90 дней).
- Итог месяца сохраняется только при полных данных. Иначе отчёт показывается, но snapshot не пишется.
- Установщик 9.8 (.exe) не пересобирался: обновление ставится архивом с `Обновить-Директор.bat`.
