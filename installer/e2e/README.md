# Сквозная проверка журнала обзвона

Браузерный тест критичной функции: результат звонка должен попасть ровно тому
клиенту, у которого нажали кнопку, даже если пока карточка открыта, выгрузка
пересобрала очередь или задача клиента исчезла (жалоба владельца 22.11.2026).

На 9.25.5 тест воспроизводит жалобу: из 7 отметок в журнал попадает 1,
остальные — «task not found» под карточкой. На 9.25.6 проходит.

Порядок (Пульт поднят в Docker, порт 8000):

    docker cp seed.py rubl_director:/tmp/seed.py
    docker cp refresh.py rubl_director:/tmp/refresh.py
    docker exec -e PYTHONPATH=/app rubl_director python /tmp/seed.py "Клиент" 0
    node journal_e2e.js <логин> <пароль> "Клиент" отчёт.json
    # жёсткий режим — задача удаляется под открытой карточкой:
    docker exec -e PYTHONPATH=/app rubl_director python /tmp/seed.py "Жёсткий" 3000
    node journal_e2e.js <логин> <пароль> "Жёсткий" отчёт.json hard

Не запускать на базе салона: seed.py добавляет тестовых клиентов.
