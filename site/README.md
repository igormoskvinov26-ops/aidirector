# Публичный сайт rublbarber.ru

Статическая витрина барбершопа. Сборки нет: это готовые файлы, которые
выкладываются в хранилище как есть.

```
index.html      главная, одностраничник
privacy.html    политика обработки персональных данных
sitemap.xml     карта сайта
robots.txt
img/            изображения (webp + jpg-запас) и видео
```

## Где размещается

Целевая площадка — Yandex Object Storage в российском регионе, режим
статического сайта. Причина переезда: прежний хостинг в Амстердаме перестал
открываться из России.

Настройки бакета: главная страница `index.html`, страница ошибки `404.html`
(ещё не сделана), `www` — переадресация на основной домен, сертификат через
Certificate Manager.

Кеширование: картинки, видео и шрифты — надолго, `index.html` — коротко,
иначе правки не дойдут до посетителей.

## Незакрытые пункты

Список доработок и критерии приёмки — в отдельном задании. Кратко, что
блокирует публикацию:

- шрифты грузятся с `fonts.googleapis.com` — единственная зарубежная
  зависимость, нужно положить рядом с сайтом. Ссылка на шрифты стоит
  **в двух файлах**: `index.html` и `privacy.html`, менять одновременно;
- два блока `shot--empty` и отсутствующие отзывы — заглушки в разметке;
- `og:image` ссылается на `img/og-cover.jpg`, а файла нет: превью ссылок
  в мессенджерах сейчас пустое;
- нет счётчика посещаемости;
- часы работы проставлены предположительно, у мастеров нет персональных
  ссылок записи, в JSON-LD остались строки «ЗАПОЛНИТЬ».

Искать по слову `ЗАПОЛНИТЬ` в `index.html`.

## Чего на сайте нет и быть не должно

Форм сбора данных, полей ввода и серверной части. Запись выполняется
виджетом YCLIENTS, данные уходят напрямую в эту систему. Это зафиксировано
в политике, и менять поведение без правки политики нельзя.
