# Шрифты для сторис

Сюда положить .ttf фирменных гарнитур — иначе сторис рисуются системным
шрифтом и уезжают из брендбука.

Нужны файлы:

| Файл | Где взять |
|---|---|
| `Manrope-Regular.ttf` | fonts.google.com/specimen/Manrope |
| `Manrope-Bold.ttf` | там же |
| `Cormorant-Bold.ttf` | fonts.google.com/specimen/Cormorant |
| `JetBrainsMono-Regular.ttf` | jetbrains.com/lp/mono |

Google Fonts отдаёт .ttf внутри архива — распаковать и положить файлы прямо сюда.
Если папка пустая, приложение один раз напишет предупреждение в лог и продолжит
работать на системном шрифте.
